# Forma Studio Changelog

## Build 22 — Phase 23: Print Pre-Press & Studio Power Workflow
- **CMYK Soft-Proofing & Out-of-Gamut Warning**: Added a live **Print Proof (CMYK)** toggle simulating coated offset ink gamut compression across all artboards, flagging out-of-gamut RGB colors (`ΔE >= 8.5`) with canvas warning outlines/badges, CMYK breakdowns, and 1-click **Snap to Print Gamut** (`src/utils/printPrepress.ts`, `src/components/PrintPrepressPopover.tsx`, `src/components/LogoCanvasEditor.tsx`, `src/App.tsx`).
- **Crop Marks, Bleed & 1x Clear-Space Margins**: Added independent Pre-Press toggles for standard exterior print **Crop Marks** (corner trim lines, 4-edge registration targets, CMYK ink control bar), **3mm Bleed Guides** (`12px` trim frame), **1x Clear-Space Margin Box** dynamically measured from logo artwork, and **8% Safe Zone** (`src/utils/printPrepress.ts`, `src/components/PrintPrepressPopover.tsx`, `src/components/LogoCanvasEditor.tsx`).
- **Quick Command Palette (`Ctrl/Cmd + K`)**: Added a Spotlight-style keyboard-navigable command palette (`Ctrl+K` / `Cmd+K` or `⌘K` header button) to search and execute any pre-press toggle, layer alignment, grouping/vector tool, artboard lockup, zoom action, theme toggle, or export dialog (`src/utils/commandRegistry.ts`, `src/components/CommandPaletteModal.tsx`, `src/App.tsx`).

## Build 21 — Phase 22: Multi-Artboard Canvas & Responsive Lockups
- **Infinite Multi-Artboard Workspace**: Replaced the single-artboard scrollable stage with an infinite CSS-transformed pan/zoom canvas (`Spacebar + Drag`, Hand tool, wheel pan, `Ctrl/Cmd + Wheel` zoom, `Fit` / `Fit All`, `Arrange`) supporting side-by-side responsive lockups: **Primary Horizontal** (800×600), **Stacked Badge** (800×800), **App Icon / Favicon** (512×512), and **Social Banner** (1200×400) (`src/utils/multiArtboard.ts`, `src/components/LogoCanvasEditor.tsx`, `src/App.tsx`).
- **Global Brand Color & Font Tokens**: Linked layer fills, strokes, icon multi-tone accents, fonts, and artboard backgrounds to centralized `BrandTokens` (`primary`, `accent`, `secondary`, `text`, `background`, `display`, `tagline`). Editing any token in the Brand Kit sidebar or floating fill/font/background popovers updates all linked layers across every artboard simultaneously (`src/types/logo.ts`, `src/utils/brandTokens.ts`, `src/components/EditorLeftSidebar.tsx`, `src/components/FloatingContextToolbar.tsx`, `src/components/GradientPatternPicker.tsx`).
- **Multi-Artboard Persistence**: Persisted `artboards`, `activeArtboardIndex`, and `brandTokens` in session storage and project records (`src/utils/projectStorage.ts`, `src/App.tsx`).
